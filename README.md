# NextStep Computer Institute — Website Demo

A responsive React + Vite website for a computer training institute, prepared as a project assignment starter.

## Features
- Responsive navigation with mobile menu
- Hero section, course cards, about/benefits, learning approach, FAQ accordion, contact form and footer
- Course enquiry form that prepares a message in the visitor's email application
- Responsive layout, keyboard focus styles, reduced-motion support and subtle interactions
- Built with React, CSS and Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Build for deployment
```bash
npm run build
```
Vite creates the production site in `dist/`.

## Deploy to GitHub and Vercel
1. Create a new GitHub repository with no README/license pre-created.
2. Open a terminal in this project folder and run:
   ```bash
   git init
   git add .
   git commit -m "Build computer training institute website"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   git push -u origin main
   ```
3. In Vercel, import that GitHub repository. Use `npm run build` as the build command and `dist` as the output directory.

## Important: personalize before publishing
This is a demo brand called **NextStep Computer Institute**, not a verified real business. The assignment asks for a real business website, so replace:
- Institute name and logo/branding
- Address, phone number, email and social links
- Course names, course durations, fees and schedule information
- Any placeholder contact information and sample claims
- Stock photos if you have photos of the real institute

The contact form currently uses a `mailto:` link to `hello@nextstepinstitute.example`. Replace it with a real email address before publishing. The form does not store or submit information to a server.
